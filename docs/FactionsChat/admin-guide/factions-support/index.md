# Factions Support Overview

FactionsChat3 integrates with several versions of Factions.

## Supported Factions Versions

- **[Factions3 Renewed](../../../Factions):** This is our version of Factions that we recommend
- **[PvPIndex-Factions](https://www.spigotmc.org/resources/1-21-26-1-pvpindex-factions-api-faction-power-faction-claims-gui.135322/)**
- **[TeamsAPI](https://www.spigotmc.org/resources/teams-api.134803/):** Any Factions/Teams plugins that integrate with TeamsAPI will work with FactionsChat.

## FactionsBridge

FactionsChat supports [FactionsBridge API](https://www.spigotmc.org/resources/factionsbridge.89716/) to integrate with other Factions plugins that don't have a direct integration currently.

!!! warning Note
    We have not tested integrations with any plugins that work with [FactionsBridge](https://www.spigotmc.org/resources/factionsbridge.89716/). If you install FactionsBridge along with your Factions plugin and encounter issues, please [Submit an Issue](https://github.com/JeremyFail/MassiveCraft/issues) on Github.

## Standalone Mode

FactionsChat3 will function without a Factions plugin. It will operate in a reduced functionality mode (any Factions-specific functionality will not work).
