# Integrations Overview

In addition to the main integrations with various versions of Factions, FactionsChat integrates with several external plugins to enhance functionality and provide seamless compatibility with your server ecosystem.

## Supported Integrations

- **[PlaceholderAPI](placeholderapi.md):** Advanced placeholder support
- **[DiscordSRV](discordsrv.md):** Optional relay for staff chat to Discord
- **[EssentialsX](essentialsx.md):** SocialSpy support for monitoring private channels

## Getting Help

If you're experiencing issues with integrations:

1. Check the specific integration documentation
2. Verify plugin versions are compatible
3. Review server console for error messages
4. Test with minimal plugin setups to isolate issues
5. Consult the [GitHub repository](https://github.com/JeremyFail/MassiveCraft/issues) for known issues

### Best Practices
- Always test integrations after plugin updates
- Check console for integration warnings or errors
- Verify configurations after server restarts
