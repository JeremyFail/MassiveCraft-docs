# Welcome to MasiveCore

MassiveCore is a dependency library that is required to run various MassiveCraft plugins which are being maintained and are documented on this site.

We may try to get rid of the need for MassiveCore in the future, as it's unlikely that many plugins these days actually use it other than the original MassiveCraft plugins and their various forks, such as those being maintained here.

## How do I install MassiveCore?

While MassiveCore does have a few commands and configuration settings, you should not need to use these under most circumstances. Simply place the MassiveCore JAR in your plugins directory with the actual plugin(s) you're using, and that will allow any plugin(s) that require it to use the MassiveCore library and function as it should.
