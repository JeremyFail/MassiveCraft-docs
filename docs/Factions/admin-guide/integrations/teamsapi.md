# TeamsAPI Integration

Factions acts as a "provider" for [TeamsAPI](https://www.spigotmc.org/resources/teams-api.134803/). TeamsAPI acts as a bridge to provide a standardized API for "teams" plugins, such as Factions. This allows any plugin that integrates with TeamsAPI to immediately be compatible with Factions.

!!! info "Note"

    For more information about TeamsAPI, visit their plugin listing page or [Wiki](https://ez-plugins.github.io/teams-api/).


## Installation

1. Install TeamsAPI on your server
2. Install Factions
3. Install the plugin that integrates with TeamsAPI

No additional configuration is required - the integration is automatic and the integrating plugin will work with Factions.
