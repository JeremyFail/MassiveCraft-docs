# Welcome to CreativeGates

CreativeGates is a simple, powerful portal plugin for Minecraft Spigot/Paper servers. It allows players to create teleportation gates and build gate networks without running a single command.

## What is CreativeGates?

CreativeGates enables players to create instant teleportation portals between different locations on your server. Players can build portal frames using any blocks, activate them with simple tools, and travel seamlessly between connected gates in the same network.

## Key Features

- **No Commands Required**: Players create gates through intuitive building and item interactions
- **Flexible Design**: Portal frames can be any size and shape, as long as they're enclosed
- **Network System**: Gates with the same name automatically link together
- **Player-Friendly**: Simple tools for gate creation, inspection, and management
- **Admin Control**: Comprehensive permissions and configuration options
- **Lightweight**: Minimal server impact with efficient teleportation

## Quick Start

=== "For Players"
    1. Build a rectangular frame with any solid blocks
    2. Include the required frame blocks (default: 2 emerald blocks)
    3. Use a named clock to activate the portal
    4. Repeat at another location with the same network name
    5. Walk through to teleport!

=== "For Admins"
    1. Install [MassiveCore](../MassiveCore/) (required dependency)
    2. Install CreativeGates plugin
    3. Configure permissions as needed
    4. Optionally customize settings in the configuration file
